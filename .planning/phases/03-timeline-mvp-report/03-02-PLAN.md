<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| evidence-controlled strings → report.html | Filenames/paths/file-type/limitation strings are adversarial and rendered into HTML — the primary injection surface. |
| caller-supplied case_dir → report file paths | Output paths must stay inside case_dir. |
| huge real timeline → HTML rendering | Multi-million-event timelines can exhaust memory if fully materialized for HTML. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering / Elevation | report.html.j2 evidence values | mitigate | Jinja2 autoescape ON (select_autoescape html/j2); no `| safe`/`Markup()` on evidence values; tested with a `<script>`-bearing filename (test_html_autoescape). |
| T-03-07 | Tampering | report file output path | mitigate | Paths built only from case_dir + fixed names (report.json/report.html); reuse audit/log.py `_is_within` realpath confinement; create reports/ like logs/. |
| T-03-08 | Denial of Service | HTML timeline rendering | mitigate | D-27 bounded view via get_timeline_events(limit=cap); HTML reads a bounded slice, never materialize-then-slice the full set (Pitfall 5). |
| T-03-09 | Information Disclosure (misleading) | truncation / findings honesty | mitigate | Real "Showing N of M" disclosure (only when truncated); mandatory Limitations section with standing MVP disclaimer; FAT provenance flags surfaced; no human-intent phrasing (UI-SPEC tone rules). |
| T-03-10 | Repudiation | non-deterministic markup | mitigate | No datetime.now/run-id/host in body markup; deterministic Jinja2 whitespace; iterate already-sorted timeline list; run-metadata in excluded footer (foundation for the CLI-02 byte test in 03-03). |
</threat_model>
