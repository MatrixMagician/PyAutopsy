| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-04 | Tampering / Elevation | Zip Slip / path traversal on extract | mitigate | `realpath` confinement per member + reject `..`/absolute; tar `filter='data'` (explicit, all Python versions); manual confinement for zip (no stdlib filter) — 01-RESEARCH.md §Safe-Extraction §1–3. |
| T-1-04-A | Tampering / Elevation | symlink / hardlink / device-file escape | mitigate | `filter='data'` refuses these for tar; explicit external-attr symlink-mode check for zip; benign-only members written into the jail (V12). |
