| caller → case store | case dir / metadata values originate from CLI args (untrusted strings) |
| caller → audit log path | the log path must always resolve under the case dir, never the evidence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-05 | Repudiation | case store COC rows | mitigate | Case/evidence rows record examiner, evidence_id, acquisition source, sha256/md5, tool+TSK versions, UTC timestamps — an attributable chain-of-custody record (REPORT-01). |
| T-1-06 | Repudiation / Tampering | audit log | mitigate | Append-only `O_APPEND` JSONL + `fsync` per event; deterministic sorted keys; written only under `<case_dir>/logs/`, never near evidence (D-09, PITFALLS P12). |
| T-1-01-A | Tampering | audit log path injection | mitigate | The log path is always recomputed as `<case_dir>/logs/audit.jsonl`; any caller-supplied path that resolves outside the case dir is rejected with a specific exception (V4 access control / confinement). |
| T-1-01-B | Information Disclosure | case store contents | mitigate | All writes confined to the case dir; no network egress; SQLite file is single-file and hashable for COC (PITFALLS P11; D-03). |
