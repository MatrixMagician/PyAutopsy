<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args (untrusted strings) → orchestrator | image path, case dir, examiner, evidence-id, acquisition-hash all originate from the operator/shell |
| source image → ingest flow | must be opened read-only and must never be mounted or written |
| all output → case dir | case.db + audit log must land only in the case dir, never near the evidence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-03 | Tampering / Repudiation | ingest path handling | mitigate | Write-guard rejects a case dir inside/equal to the evidence path (D-01); `assert_source_not_mounted` refuses mounted sources; source opened read-only via the seam; mtime/size asserted unchanged (INGEST-03, P1). |
| T-1-02 | Repudiation | integrity outcome | mitigate | Acquisition compare PASS/FAIL + end-of-run re-verify; any mismatch → non-zero exit AND a recorded FAIL audit event before propagation (D-08, P2). |
| T-1-05 | Repudiation | COC persistence | mitigate | `cases` + `evidence_sources` rows record examiner, evidence_id, source, hashes, tool+TSK versions, UTC times (REPORT-01). |
| T-1-06 | Repudiation / Tampering | audit completeness | mitigate | Every action (start/guard/init/open/hash/compare/reverify/end + errors) is appended to the JSONL audit log (REPORT-02, P12). |
| T-1-03-A | Tampering | CLI input validation | mitigate | Typer type-hint-driven validation of required options; paths resolved/validated before use (ASVS V5). |
| T-1-03-B | Information Disclosure | output confinement | mitigate | All writes (case.db, audit log) confined to the case dir; no network egress (PITFALLS P11). |
</threat_model>
