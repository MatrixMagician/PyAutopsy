<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| examiner NSRL DB path → sqlite3 | Untrusted file path; opened as read-only data, never as case.db |
| custom hash-set file → parser | Untrusted text (mixed case, comments, malformed lines) |
| file hashes → NSRL SQL query | Hash hex flows into a parameterized query |
| matcher → CaseStore | Only neutral annotation rows cross; sole-writer rule holds |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-SQLI | Tampering | NSRL membership query | mitigate | Parameterized `?` placeholders only; table name from the fixed {FILE, METADATA} allowlist; never string-format a hash into SQL |
| T-04-02-DBRO | Tampering/Elevation | malicious NSRL DB path (write/attach side effects) | mitigate | Open with `?mode=ro` + `PRAGMA query_only=ON`; never `ATTACH`; treat as read-only input |
| T-04-02-CASE | Spoofing (of findings) | NSRL UPPERCASE vs our lowercase hashes (silent zero-match) | mitigate | `.upper()` normalize the probe + runtime table discovery; locked by the FILE/METADATA fixture DBs (Pitfall 4) |
| T-04-02-PARSE | Tampering | malformed custom hash-set lines | mitigate | Skip blank/comment lines; hex-validate; accept only lengths {32,40,64}; lowercase-normalize |
| T-04-02-VERDICT | Repudiation | surfacing a good/bad verdict instead of neutral "known" | mitigate | Match model carries source/list/sense only; report uses noise-reduction framing; no good/bad key anywhere (D-38) |
| T-04-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages (research audit: none); filtering is stdlib sqlite3/hashlib only |
</threat_model>
