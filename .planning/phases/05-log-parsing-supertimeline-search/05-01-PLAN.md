## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| on-disk log text + filenames → parser | Untrusted evidence bytes and rotated-set filenames parsed inside log/ (decoded as DATA, never a write path). |
| disk image → byte/FS seam | Source image read-only via the two allowlisted seams; never mounted, never written. |
| examiner CLI args → run_logs | `--case`/`--image` paths validated; case-open failure is a clean operator error, not a crash. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Tampering | malicious log content (control chars / report injection) | mitigate | Decode utf-8/errors="replace", treat as data only; report HTML uses jinja2 autoescape (already on). |
| T-05-01-02 | Tampering | source image mutation during parse | mitigate | `integrity.assert_source_not_mounted` re-asserted before+after open; all reads via read-only seams; covered by tests/test_readonly_guarantee.py. |
| T-05-01-03 | Information disclosure | inferred tz/year presented as fact | mitigate | D-46 honest flagging — `timestamp_source` + assumed_timezone/year recorded per event; UTC fallback warned (SOUND-02). |
| T-05-01-04 | Denial of Service | gz rotation decompression bomb | mitigate | Cap inflated bytes per gz member (reuse safe_extract size-cap ethos); stream, don't slurp (PERF-01). |
| T-05-01-05 | Tampering | parsed log path used as a write target (Zip-Slip-class) | mitigate | Parsed paths are DATA; no export path in this slice; any future export routes through `util/safe_extract._confined_target`. |
| T-05-01-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs; tests/test_no_new_deps.py (Wave 0) blocks any new runtime dep (D-43). Package Legitimacy Audit: not applicable (zero external packages). |
</threat_model>
