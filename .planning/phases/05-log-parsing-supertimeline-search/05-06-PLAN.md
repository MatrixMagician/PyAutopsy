<objective>
Close gap **G-1 (minor, advisory — UAT test 3 PASSED)**: the D-46 mtime-anchored year inference
is forensically SOUND, but the committed fixture and its documented ground truth disagree about
the year.

Root cause (confirmed from make_fixtures.py): the ext4 fixture is built with a frozen debugfs
clock `_EXT4_FAKE_TIME = "1700000000"` (= 2023-11-14), so EVERY filesystem mtime lands at
2023-11-14. D-46 seeds the RFC3164 year from the log file's mtime, so inference CORRECTLY yields
~2023 (and 2022 for the Dec-of-prior-year rotated member). But the sidecar constants assert
`LOG_SEARCH_YEAR = 2026` / `LOG_SEARCH_PREV_YEAR = 2025`. The mechanism is right; the documented
expectation is wrong. (Epoch-anchored shell-history lines are unaffected — they resolve from
embedded epochs to 2025-01-15 regardless.)

**Remediation chosen: Path B (correct the sidecar to the values the fixture actually produces).**

Justification (lower-risk path, per the gap remediation note):
- Path A (rebuild the .img with a ~Jan-2026 fake mtime) requires host `mkfs.ext4`/`debugfs`, CHANGES
  the committed image bytes AND its sha256 — which forces a lockstep update of UAT test 11's
  read-only baseline `6e41afad...079b0` and every test/doc asserting that hash, and re-derives all
  68 filesystem MACB timestamps in the super-timeline (cascading byte-determinism churn).
- Path B touches only the documentation sidecar + the constants that generate it. The committed
  `.img` and its sha256 are untouched, so the read-only forensic baseline and all hash assertions
  remain valid with NO lockstep edit. It makes generator, sidecar, and the (sound) D-46 inference
  agree at the value the evidence actually carries.

Purpose: remove the fixture-vs-sidecar documentation drift so the corpus self-documents the years
the tool truly infers (relates to verification WR-01, year-wrap fixture verification).

Output:
- `LOG_SEARCH_YEAR` / `LOG_SEARCH_PREV_YEAR` in make_fixtures.py corrected to the
  `_EXT4_FAKE_TIME`-anchored values, with a comment tying them to the frozen-clock mtime.
- `log_search_groundtruth.json` regenerated/edited to match (year + prev_year).
- A guard test that pins the sidecar year to the fixture's actual mtime-anchored inference so the
  drift cannot silently reappear.
</objective>
